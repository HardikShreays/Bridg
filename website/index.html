How it works

Paired in under a minute.

No sign-up and no cables. Scan once and it reconnects by itself from then on.

Watch the setup video ↗

Install both apps

Grab Bridg for Mac and the Android APK below. Both are free and open source.

Scan the QR code

Open Bridg on your Mac, then scan the code with your phone. Keys are exchanged right there.

That's it

Same Wi-Fi? You're connected. Updates are one click, via Check for updates in either app.

Private by design

Your data never leaves your network.

No servers, no accounts, no telemetry. Bridg talks directly between your devices, and every frame is encrypted with keys only they hold.

$ bridg handshake
→ X25519 key exchange ✓
→ fresh per-session salts ✓
→ sealed frames, replay-protected ✓
  • ✓
    End-to-end encrypted. X25519 pairing, a new session key on every connect.
  • ✓
    Local network only. Bonjour discovery, straight TCP between devices. Nothing is relayed.
  • ✓
    Open source, MIT. Read every line on GitHub, or build it yourself.
  • ✓
    Lightweight. A native Swift menu bar app and a Kotlin service. No Electron.
